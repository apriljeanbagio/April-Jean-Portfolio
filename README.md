# April Jean Personal Portfolio Website

## Project Description
The April Jean Personal Portfolio Website is a dynamic portfolio system developed using PHP, MySQL, HTML, CSS, and JavaScript. It is an upgraded version of my midterm personal portfolio website.

Visitors can view my personal information, skills, educational background, projects, experience, achievements, and contact information.

The system also includes an Admin Dashboard for managing website content without manually editing the source code.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Git and GitHub

## Main Features

### Public Website
- Home
- About Me
- Skills
- Projects
- Resume
- Contact Form

### Admin Dashboard
- Administrator login and logout
- Dashboard statistics
- Profile management
- Skills management
- Projects management

- Contact message management

### Security Features
